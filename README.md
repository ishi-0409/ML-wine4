# 概要
wineのデータセットを標準化を行い、目的変数(quality)に対する説明変数が与える影響の大きさをそれぞれの回帰係数によって評価する  

# 使用データ

データの出典([https://archive.ics.uci.edu/dataset/186/wine+quality])

データの形式(CSV,区切り文字;)

# 環境、依存ライブラリ
python(3.12.9),pandas,scikit-learn

# データの理解
説明変数の統計量を調べる  
説明変数の間で平均値が10程異なる  

# データの前処理
標準化を行い、データのスケールを合わせる  
外れ値の除外は今回行っていない(外れ値の除外を行った方がより精度が上がると思われる)  

# モデルの構築
train_test_splitを用いてデータを訓練用とテスト用に説明変数、目的変数ともに分割する  
今回分割の比率は 4:1で行っている  
モデルの学習においては、標準化を行った説明変数の訓練用データと目的変数の訓練用データを用いる  

# モデルの評価
説明変数それぞれの回帰係数を出力する  
回帰係数: [ 0.03978916 -0.17943891 -0.02751248  0.00942128 -0.08908432  0.05801491
 -0.12000836 -0.01920444 -0.06061037  0.14681503  0.2966275 ]  

上記の結果から、alcoholが最も影響が大きく、volatile acidityが最も影響が小さかった
